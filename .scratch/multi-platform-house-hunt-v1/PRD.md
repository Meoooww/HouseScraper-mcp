# Multi-Platform House Hunt V1

## Goal

Build a local MCP service that can help with house-hunting across `beike`, `lianjia`, and `anjuke`, starting with broad search and verification workflows that can be checked against a real phone browser.

## Success criteria

- The service can repeatedly verify that all supported platforms still return live data.
- The service can search across multiple platforms with a normalized schema.
- The service can support both broad filtering and spot-check verification of specific listings.
- The user can export a shortlist for manual comparison outside the MCP client.

## Scope for this wave

1. Multi-platform live baseline and regression command
2. Community/building keyword search
3. Cross-platform aggregation and deduplication
4. Listing detail and price verification
5. Candidate export
